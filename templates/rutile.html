Rutile

A local-first native Markdown editor written in Rust. A fast source editor and a live preview in one small app — no Electron, no cloud, no plugins, no telemetry.

Download 0.2.3 preview (macOS) Source on GitHub

Free, MIT licensed. Your notes stay plain Markdown files on your disk.

Why local-first matters for writers

Your notes are the one dataset you keep for decades. Rutile treats every file as yours: it reads and writes plain Markdown on your disk, keeps a checksummed crash-recovery journal so unsaved work survives a crash, and never phones home — there is no home to phone.

What's inside

  • Typed Rust core — a rope-based editor with revisioned, stale-rejecting edit transactions.
  • Native shells — Iced/AppKit on macOS, GTK3 on Linux. The system webview renders only your sanitized preview, under a strict CSP; untrusted raw HTML never executes.
  • Find, format, export, tabs, focus mode, command palette — the writing stack, without IDE baggage.
  • Evidence-first engineering — reproducible release builds, per-artifact provenance records, and ed25519-signed publication authorizations you can verify yourself (below).

Verify what you download

Every release artifact carries a reproducible-build provenance record and a release-authority signature over that exact file. Check the SHA-256 of your download:

Rutile-0.2.3-macos-arm64.app.zip
4979ec396cf43ef4e0da10fe5984d5d5060069567bb37256d9749e833a4f4363
Rutile-0.2.3-macos-arm64.dmg
16269b3935a305fa4eac19f9ea50eb406d92abf7b5b23d1e7d3072775dfc0368

The signing key's fingerprint is pinned in the repository (release/keys/release-authority-v1.pub.hex); the .preview-authorization.json beside each download is that key's signature binding the artifact to its provenance record.

Honest status: preview tier

0.2.3 ships at the preview tier: every artifact is provenance-backed and signed, but the macOS build is ad-hoc codesigned (not notarized) and the full production tier — an independent-verifier readiness ceremony over a five-runner matrix — is still ahead. Linux packages follow that ceremony. We'd rather tell you the exact state of the software than round up.

Build it yourself

git clone https://github.com/KyaniteLabs/rutile
cd rutile && cargo run --locked -p rutile-app --no-default-features --features macos-shell
