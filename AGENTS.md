# Project agent contract

Read the repository README and current app runbooks before coding. Keep this
file limited to stable project rules; do not copy provider, host, port, issue,
release, or task snapshots here.

- Preserve dirty work and keep edits scoped.
- Verify current branch, remote, tests, CI, and runtime state before claims.
- Reuse existing scripts and patterns; do not hardcode secrets.
- Run focused checks for changed surfaces before delivery.
- Stop before external, credentialed, public, financial, or destructive actions
  without explicit approval.
