# kyanite-landing

KyaniteLabs landing page, company website, and product showcase.

## Rules

- Commits explain why; keep pull requests under 400 lines when practical.
- Rebase feature branches instead of merging them; never skip CI.
- Never hardcode secrets, validate paths, use HTTPS for external calls, and pin dependencies.
- Test user-visible behavior and unhappy paths; remove orphaned or commented-out code.

## Local hygiene and verification

- Inspect status, remotes, and current deployment instructions before editing.
- Keep changes scoped; do not commit, push, or deploy without authorization.
- Run the narrowest relevant checks and inspect the rendered page for visual changes.
